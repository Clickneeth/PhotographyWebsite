# Auto-Caption Watcher (local)

Drag any photo into `drop/` and it will automatically:
1. Get captioned by a local vision LLM (`moondream` via Ollama — nothing
   uploaded anywhere)
2. Get renamed into the next number in your `assets/` sequence
3. Get added to `gallery.json`, which the site now reads to build the
   gallery and display captions (hover title on thumbnails, caption text
   under the modal image)

## How it runs
A LaunchAgent (`~/Library/LaunchAgents/com.shankar.captionwatcher.plist`)
keeps `caption_watcher.py` running persistently in the background (starts at
login, restarts if it crashes) so dropping a photo works at any time without
you having to open a terminal.

## Manual run (for testing/debugging)
```
~/Desktop/ProjectPortfolio/venv/bin/python3 ~/Desktop/ProjectPortfolio/caption_watcher.py
```

## Managing the LaunchAgent
```
launchctl unload ~/Library/LaunchAgents/com.shankar.captionwatcher.plist   # stop
launchctl load ~/Library/LaunchAgents/com.shankar.captionwatcher.plist     # start
```

## Notes
- Existing 60 photos were seeded into `gallery.json` with empty captions
  (nothing broke) — they won't get auto-captioned unless you re-drop them
  through `drop/` (this would also renumber them at the end of the sequence,
  so only do this deliberately, not automatically).
- Captions are AI-generated by a small local model — quality is decent but
  not perfect; edit `gallery.json` directly anytime to fix a caption by hand.
- If you view the site locally via `file://` (double-clicking index.html),
  the browser will likely block `fetch("gallery.json")` due to CORS. Run a
  local server instead: `python3 -m http.server` in this folder, then open
  `http://localhost:8000`. This restriction does not apply once deployed to
  GitHub Pages.
